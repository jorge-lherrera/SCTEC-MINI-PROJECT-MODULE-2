# MedClinic API

API back-end para o gerenciamento de uma clínica médica de pequeno porte.

Esta etapa entrega exclusivamente a **base de acesso do sistema**: cadastro de usuários,
autenticação via JWT e autorização baseada em perfis (RBAC). As funcionalidades de domínio
da clínica (especialidades, médicos, pacientes e consultas) serão construídas sobre esta base
em uma etapa futura.

**Stack:** Node.js · TypeScript · NestJS (Express) · TypeORM · PostgreSQL

> Documentação completa (instalação, configuração, arquitetura e endpoints) em desenvolvimento.
